# Draft Play Store listing

## App name

Liar's Luck

## Short description

Hear the mystery sound. Spot the bluff. Challenge a friend in real time!

## Full description

Think you can tell a real claim from a bluff? Bring a friend into a private
Liar's Luck room and find out.

Listen to the mystery sound, read the item claim, and choose Truth or Bluff.
Both players lock in their answers privately. When you have both voted, reveal
the real item and see who earned the points. New rounds start automatically,
so the rivalry can keep going.

FEATURES
- Play with a friend using a six-character room code
- Hear the same mystery sound and see the same claim each round
- Keep your answer secret until both players have voted
- Compete with live scores and streaks
- Jump into a match from a shared room invite

An internet connection is required to play online. Player names and game
rounds are processed temporarily to run a room; accounts, chat, and a saved
match-history feature are not provided.

Liar's Luck is an independent game and is not affiliated with or endorsed by
Roblox Corporation.
